# 보안 규칙

저장소는 **Public**이에요. 올리는 모든 것이 보인다고 생각하고 일해요.

## 비밀 정보

- API 키, 비밀번호, 토큰, `.env`, `*.pem`, `*.key`는 커밋하지 않아요. `.gitignore`가 막아 줘요.
- 키가 한 번이라도 커밋되면 즉시 폐기하고 새로 발급해요. 이력 삭제만으로는 부족해요.
- 커밋 메시지와 PR 본문에 로컬 경로, 토큰, 이메일을 쓰지 않아요.
- 스크린샷은 올리기 전에 이메일, 토큰, 개인 링크, 사설망 주소를 가려요.

## 개인정보

- 참가자 이름, 소속, 학교, 연락처는 필요한 만큼만 적어요.
- 참여 확정 페이지의 개인 링크는 저장소에 쓰지 않아요.

## 애플리케이션

- 사용자 입력은 서버에서 검증해요.
- 세션과 메모는 소유자만 읽고 써요. 소유자 격리 테스트를 유지해요.
- 녹음은 동의 기록이 있을 때만 처리해요. 철회하면 멈춰요.
- Docker 이미지와 Helm 값에 비밀 정보를 굽지 않아요. 환경 변수나 Kubernetes Secret으로 넣어요.
- AWS 자격 증명은 최소 권한으로 쓰고, 장기 키 대신 SSO나 역할을 써요.
- 모델 공급자 키(Bedrock, OpenAI)는 `.env`로만 넣어요. Codex 토큰은 Codex가 보관해요.

## 외부 코드

- 가져온 코드와 디자인은 출처, 버전, 라이선스를 남겨요. 출처를 모르는 코드는 넣지 않아요.

자세한 내용과 제출 전 체크리스트는 `docs/EVALUATION_GOVERNANCE_SECURITY.md`를 봐요.
