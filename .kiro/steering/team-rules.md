# 팀 작업 규칙

이 저장소에서 일하는 모든 에이전트는 작업 전에 이 규칙을 따라요. `AGENTS.md`와 같은 내용이에요.

## PR

- PR 본문 첫 줄에 만든 주체를 적어요. 예: `Opened by: 문서기 (crew-ccd60e20d13a627f)`.
- 사람이 연 PR은 사람 이름을, 여러 Bot이 함께 만든 PR은 주된 Bot을 먼저 적어요.

## 커밋

- 제목 형식은 `<gitmoji> <type>(<domain>): <title>`이에요. 한글로 써도 돼요.
- 본문에는 이유를 한두 문장으로 적어요. 로컬 경로, 토큰 같은 민감한 정보는 넣지 않아요.
- Kiro Crew Bot의 커밋은 GPG 서명을 쓸 수 없어서 서명하지 않아요. 그래서 PR로만 올려요.

## 브랜치와 push

- `main`에 직접 push하지 않아요. `crew/<영역>/<주제>` 브랜치에서 PR을 열어요.
- 제출 마감(18:00) 전에 마지막 커밋을 push하고 PR 링크를 제출 폼에 넣어요.

## 비밀 정보

- API 키, 비밀번호, 토큰, `.env`는 커밋하지 않아요. `.env.example`에는 가짜 값만 둬요.

## 다른 사람의 작업

- 작업 폴더에 다른 Bot의 미커밋 변경이 있으면 건드리지 않아요. 별도 워크트리에서 작업해요.
