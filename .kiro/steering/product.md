# 제품과 행사

## 제품: Open Attendee

밋업, 이벤트, 학회, 미팅에서 직접 기록하고 참고자료를 받아, AI로 요약해 원하는 형태로 정리하는 필기 도구예요. 정리된 초안에 사용자가 인사이트를 더하고 최종 검토해요.

- 대상 사용자: 밋업, 이벤트, 학회, 미팅에 참석하는 학생과 직장인.
- 핵심 기능: 웹 필기, 녹음과 STT 전사, 사진과 발표자료 첨부, AI 실시간 요약과 정리, 템플릿 선택과 재사용, 인사이트 추가와 최종 검토.
- 녹음은 **동의를 확인한 뒤에만** 처리해요. 동의 검사는 화면이 아니라 서버에서 강제해요.
- 설치 환경: 맥북, 모바일, AWS, 온프레미스.
- 상세 요구사항, 설계, 작업 목록은 `.kiro/specs/open-attendee-webapp/`를 기준으로 해요.

## 행사: KIROTHON 2026

- 주최 AUSG x ASBG x AWSKRUG, 후원 AWS x Kiro. 장소는 AWS Korea(서울).
- 2026-11-14(토) 10:00 - 21:30. 개발은 11:00 - 13:00, 14:00 - 18:00.
- **주제:** 내 일상에 바로 적용할 수 있는 서비스. 나와 주변 사람이 매일 겪는 작은 불편을 해결하는 서비스.
- **18:00 결과물 제출 마감.** 이후 커밋은 심사에 반영되지 않아요.
- 심사 기준(1차 100점): Kiro 활용 35, 작동 30, 문제 정의 20, 사용자 가치 15. 1차는 AI가 레포(`README.md`, `BUILD_REPORT.md`, `.kiro/`)를 평가해 결선 3팀을 뽑고, 문제 정의와 사용자 가치는 운영진이 한 번 더 봐요.
- 결선 피칭은 3팀, 발표 5분 + Q&A 3분. README의 Demo 링크 영상을 녹화 데모로 써요.
- 템플릿 안내 문구만 남은 섹션은 점수에 반영되지 않아요.
