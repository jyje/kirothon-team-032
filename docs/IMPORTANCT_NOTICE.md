KIROTHON 2026은 하루 동안 Kiro로 아이디어를 서비스로 만드는 해커톤입니다. 18:00까지 GitHub 레포로 결과물을 제출하면, 1차 심사로 결선 3팀을 뽑고 결선 피칭으로 수상 팀을 정합니다.

| 항목 | 내용 |
| --- | --- |
| 일시 | 2026년 11월 14일 (토) 10:00–21:30 |
| 장소 | AWS Korea 18층 |
| 주최 | AWSKRUG × AUSG × ASBG |
| 주제 | 내 일상에 바로 적용할 수 있는 서비스: 나와 주변 사람이 매일 겪는 작은 불편을 해결하는 서비스 |

## 🚨결과물 제출

18:00 전에 마지막 커밋을 push하고 제출 폼에 레포 주소를 입력하면 제출이 끝납니다. **18:00 이후 커밋은 심사에 반영되지 않습니다.**

### 1. 레포 만들기 (개발 시작 전)

1. 템플릿 레포 kirothon-starter에서 Use this template → Create a new repository를 누릅니다.
2. 레포 이름은 `kirothon-팀번호`로 하고 **Public**으로 만듭니다. 예: 40번 팀은 `kirothon-team-040`
    1. 레포 이름에는 한글을 쓸 수 없습니다. 한글 팀명은 README 맨 아래 '팀' 섹션에 씁니다.
3. 레포를 클론해서 Kiro로 열고 개발을 시작합니다.

### 2. 꼭 채울 파일

| 파일 | 내용 |
| --- | --- |
| `README.md` | 템플릿 섹션을 모두 채웁니다: 문제 정의, 핵심 기능, 사용 시나리오, 기대 효과, 차별점, 설치와 실행 |
| README의 **Demo** 줄 | 배포 주소나 데모 영상 링크를 꼭 적습니다. 결선 피칭의 녹화 데모로도 씁니다 |
| `BUILD_REPORT.md` | Kiro를 어느 단계에서 어떻게 썼는지 표로 기록합니다 |
| `.kiro/` | Kiro에서 만든 specs, steering, hooks를 그대로 커밋합니다 |
| `PRESENTATION.pdf` | 모든 팀이 제출합니다. 발표자료를 PDF로 만들어 레포 최상단에 올립니다 |

### 3. 제출 (18:00 마감)

1. 18:00 전에 마지막 커밋을 push합니다.
2. 제출 폼에서 팀을 고르고 GitHub 레포 주소를 입력합니다. 제출 폼 링크: KIROTHON 2026 결과물 제출
3. 18:00 전까지는 제출한 응답을 수정할 수 있습니다.

### 주의

- 레포가 **비공개면 심사할 수 없습니다.** 제출 전에 로그아웃한 창(시크릿 창)에서 레포가 열리는지 확인해 주세요.
- API 키, 비밀번호, `.env` 파일은 커밋하지 마세요.
- 데모 영상은 레포에 올리지 말고 README의 Demo 줄에 링크로 적습니다. YouTube(일부 공개)나 구글 드라이브(공유: 링크가 있는 모든 사용자 · 뷰어) 모두 괜찮습니다.
- 1차 심사는 레포에 적힌 내용만 봅니다. 템플릿 안내 문구만 남은 섹션은 점수에 반영되지 않습니다.

## 심사 기준

1차 심사에서 전체 팀 중 결선 3팀을 뽑고, 결선 3팀은 19:00부터 피칭합니다(발표 5분 + Q&A 3분, 녹화 데모 포함).

| 항목 | 1차 · 전체 팀 | 2차 · 결선 3팀 |
| --- | --- | --- |
| Kiro 활용 | 35 | 20 (1차 등급 반영) |
| 작동 | 30 | 15 (녹화 데모) |
| 문제 정의 | 20 | 25 |
| 사용자 가치 | 15 | 25 |
| 발표 | – | 15 |
| 합계 | 100 | 100 |
- **1차:** 18:00 시점의 GitHub 레포(README, BUILD_REPORT, `.kiro/`)를 AI가 평가하고, 문제 정의와 사용자 가치는 운영진이 한 번 더 검토합니다.
- **2차:** 심사위원이 발표와 녹화 데모를 보고 평가합니다.

## 네트워킹 빙고와 시상

네트워킹 시간(19:25–20:25)에 Kiro 빙고를 3줄 완성하면 키로 티셔츠를 드립니다.

1. 화면에 띄워진 QR코드에 접속하여 빙고판에 접속합니다.
2. 다른 참가자와 이야기하고, 미션에 맞는 사람의 명찰 속 빙고 코드를 칸에 입력합니다.
3. 운영진 칸은 운영진 명찰의 코드만 인정됩니다.
4. 3줄을 완성하면 운영진에게 화면을 보여 주고 티셔츠를 받습니다.

## 행동강령과 문의

KIROTHON은 AWS 행동강령을 따릅니다.

- **서로 존중하기:** 차별, 괴롭힘, 위협적인 말과 행동은 허용되지 않습니다.
- **정직하게 참여하기:** 정확한 정보로 등록하고, 본인에게 발급된 명찰만 사용합니다.
- **운영 지침 따르기:** 운영진 안내와 안전 수칙을 따르고, 허가 없는 홍보는 하지 않습니다.

위반하면 참여 중단이나 퇴장, 이후 AWS 행사 참여 제한, 콘텐츠 삭제 조치가 있을 수 있습니다. 부적절한 행동을 보거나 겪었다면 현장 운영진이나 aws-events-security-concerns@amazon.com으로 바로 알려 주세요.

궁금한 점은 노란색 STAFF 명찰을 단 운영진에게 언제든 물어봐 주세요. 
퇴장할 때는 잊어버린 물건이 없는지 확인해 주세요.
