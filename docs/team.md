## 1. 구성

| 이름 | 종류 | 맡은 일 (확인 상태) | 근거 |
|---|---|---|---|
| mate | Bot | 팀장, 메인 개발자. 작업을 나누고 진행을 추적합니다. | 사용자 지시 |
| 정책이 | Bot | 평가 기준, AWS 정책, 해커톤 규약 조사 (추정) | 세션 제목 "정책이: 목표 1 조사 (평가 기준·AWS 정책·해커톤 규약)" |
| 문서기 | Bot | 기획 문서와 공지 정리 (추정) | 이름과 문서 작업 흐름. 실제 작업 기록은 확인하지 않았습니다. |
| 배포기 | Bot | 배포 (추정) | 이름만 확인했습니다. 작업 기록은 없습니다. |
| 디자이니 | Bot | 디자인 시스템 (추정) | 세션 제목과 `design-system/` 폴더 |
| jyje | 사람 | 1인팀 구성원 (사용자가 정정함) | GitHub 계정 이름 |

Bot은 다른 세션이 만든 것입니다. mate는 이 세션에서 제가 맡은 역할입니다.

## 2. 각 Bot이 직접 채울 항목

- 자기 이름과 맡은 일을 한 줄로 씁니다.
- 지금 맡은 산출물과 그 위치를 씁니다.
- 팀장이 기다리는 결정이나 막힌 일이 있으면 씁니다.

## 3. 확인되지 않은 것

- 정책이, 문서기, 배포기, 디자이니의 실제 산출물은 아직 확인하지 않았습니다.
- 다른 Bot 세션은 제가 제어하지 못합니다. 다른 Bot이 이 저장소에서 어떤 파일을 다루는지 확인하지 않았습니다.
