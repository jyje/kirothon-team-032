# KIROTHON 2026 디자인 스토리보드

참고 사이트: https://kirothon-timer.vercel.app/
근거: 사이트의 `style.css?v=15`와 화면 구조. 스크린샷으로 확인하지 않았어요. JS 동작은 힌트 문구와 CSS 클래스 이름으로 추정했어요.

## 1. 화면 구조

| 영역 | 역할 | 위치 |
|---|---|---|
| 검정 프레임 | 전체 화면 틀. 둥근 모서리, 보라 테두리 | 화면 전체 |
| 밤하늘 | 배경. 별, 달 | 프레임 위쪽 |
| 무대 | 16:10 고정 비율 영역. 캐릭터와 시계가 여기 놓임 | 가운데 아래 |
| 말풍선 | 제목 입력. 왼쪽 위 | 무대 왼쪽 위 |
| Kiro 캐릭터 | 장식과 상태 표시. 왼쪽 | 무대 왼쪽 |
| 시계 | 모드 이름, 큰 숫자, 진행 막대, 한마디 | 무대 오른쪽 |
| 컨트롤 | 버튼과 모드 선택 | 화면 아래 가운데 |
| 힌트 | 단축키 안내 | 오른쪽 아래 |

## 2. 화면 상태

| # | 상태 | 시계 표시 | 컨트롤 | 바뀌는 점 |
|---|---|---|---|---|
| S1 | 대기 | 00:00, 모드 이름 "STOPWATCH" | 시작, 프리셋, 모드 선택 | 기본 상태 |
| S2 | 실행 중 | 숫자가 올라가거나 줄어듦 | 정지, 리셋 | 마우스를 안 움직이면 컨트롤 숨김 |
| S3 | 임박 | 보라색 글자 | 그대로 | 프레임 테두리가 빛남 (urgent) |
| S4 | 마감 모드 | 제목 크기 작아짐 (deadline) | 그대로 | 마감 시각 기준 카운트다운 |
| S5 | 시간 종료 | "boo" 문구, 보라색, 흔들림 | 리셋 | 화면 5번 깜빡임 (flash) |
| S6 | 파티 | 무지개 색 글자, 미러볼, 조명 회전 | 그대로 | 마감 이후. Kiro 춤 |
| S7 | 전체화면 | 크게 | 숨김 가능 | F 키 |
| S8 | 이벤트 목록 | 패널 열림 | 닫기 | E 키 |

## 3. 흐름

```
S1 대기 --Space--> S2 실행 중 --Space--> S1 (정지 후 대기)
S2 실행 중 --임박 시간--> S3 임박 --마감 시각--> S4 마감 모드
S4 --시간 0--> S5 시간 종료 --R--> S1
S4 --마감 이후--> S6 파티
아무 상태 --F--> S7 전체화면 (토글)
아무 상태 --E--> S8 이벤트 목록
```

## 4. 상호작용

| 입력 | 결과 |
|---|---|
| Space | 시작 / 정지 |
| R | 리셋 |
| ↑ / ↓ | 1분 더하기 / 빼기 |
| M | 모드 전환 |
| F | 전체화면 |
| E | 이벤트 목록 |
| P | 파티 화면 미리보기 |
| 제목 클릭 | 말풍선 글자 입력 |
| 마우스 멈춤 (실행 중) | 컨트롤과 힌트 숨김 |

## 5. 한마디 (quip)

시계 아래에 잠깐 떠올랐다 사라지는 한 줄이에요. 나타날 때 살짝 튀는 움직임이 있어요. 임박 상태에서는 보라색으로 바뀌어요. 문구 목록은 원본 JS를 확인해야 해요.

## 6. 움직임

| 이름 | 쓰는 곳 | 시간 |
|---|---|---|
| breathe | Kiro 캐릭터 상시 | 6초 반복 |
| float | 장식 별 | 5초 반복 |
| twinkle | 별 반짝임 | 3초 반복 |
| shoot | 별똥별 | 1.4초 |
| quip | 한마디 | 4.2초 |
| hop | Kiro 깡총 | 1.2초 |
| flash | 시간 종료 | 1초 x 5 |
| dance | 파티 Kiro | 0.9초 반복 |

`prefers-reduced-motion`이 켜지면 모든 움직임을 끕니다.

## 7. 템플릿으로 만들 것

- 타이머 화면 (S1~S6)
- 말풍선 제목 컴포넌트
- 컨트롤 바 (버튼, 세그먼트 모드 선택, 프리셋)
- 진행 막대
- 한마디 줄
- 파티 배경 (선택)

## 8. 열린 질문

- S7, S8 화면 모습은 아직 확인하지 않았어요.
