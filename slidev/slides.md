# Open Attendee

무언갈 들으러 가는 당신을 위한 필기 도구

Kirothon 2026 Seoul · 팀 Studio.R4iny (team-032)

1인팀 + Kiro Crew AI 에이전트 팀

---

# 문제

밋업, 이벤트, 학회, 미팅에 다녀오면 기록이 흩어져 있습니다.

- 녹음 **3~4시간**, PDF와 PPT가 **다량**
- 기록에 쓰는 서비스는 **10개 이상**
- 서비스마다 **새 구독료**
- 사용량 제한, 필요한 세부 기능은 없음

정리에 **2~3시간**이 듭니다.

---

# 해결

한곳에서 기록하고, AI가 정리하고, 사람이 끝냅니다.

1. **기록**: 필기, 사진, 발표자료, 참고자료
2. **AI 요약**: 기록을 읽고 초안을 만듭니다
3. **출처**: 모든 문장에 어디서 왔는지 붙입니다
4. **검토**: 내 인사이트를 더하고, 사람만 승인합니다
5. **내보내기**: 승인한 초안만 마크다운으로 받습니다

---

# 출처와 검증

AI가 쓴 글을 그대로 믿지 않게 만들었습니다.

- 초안의 **모든 문장에 출처**를 붙입니다 (어느 메모, 어느 쪽, 어느 사진)
- 출처가 뒷받침하는지 AI가 **한 번 더 확인**합니다
- 확인되지 않은 문장은 **미검증**으로 표시합니다
- 사람이 처리하고 **승인하기 전에는 내보내지 않습니다**

---

# 구조

```text
브라우저 (Vue 3 + Vite)
   │  /api  (JSON, 쿠키 세션, CSRF)
   ▼
FastAPI 서버 ─ SQLite ─ 파일 저장소
   │
   └─ provider-manager (OpenAI / Bedrock)
```

- 이미지 하나로 실행합니다 (amd64, arm64)
- 맥북, 컨테이너, Kubernetes (AWS, 온프레미스)
- 새 구독료 대신 **내 AWS, 내 서버, 내 AI 구독**

---

# 개인정보와 보안

- **녹음은 동의 기록이 있어야만** 처리합니다. 서버가 두 번 막습니다.
- 사진 **위치 정보(EXIF)는 저장하지 않습니다**
- 로그인, CSRF 검사, 접속자 IP별 시도 제한
- 비밀 값은 환경 변수와 Secret으로만 받고 로그에서 가립니다
